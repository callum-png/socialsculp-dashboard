What should Mission Control show you?

Select all the modules you want in the initial build. We can always add more later.

1

Status & Heartbeat

Live indicator: is OpenClaw running, idle, or dead? Last heartbeat timestamp, uptime, current state (working / waiting / error). The "is he actually working?" at a glance.

2

Task Feed

Real-time log of what OpenClaw is doing: task name, status (running/completed/failed), duration, output summary. Like a GitHub Actions feed but for your AI CEO.

3

Token & Cost Tracker

How many tokens burned today/this week/this month, estimated cost, burn rate, budget remaining. Charts showing usage over time. Alerts when approaching limits.

4

Workflows & Automations

List of OpenClaw's configured cron jobs, workflows, and automations. See what's scheduled, last run time, next run, success/failure history. Enable/disable from the dashboard.

5

Live Log Viewer

Tail OpenClaw's stdout/stderr in real-time from the dashboard. Like SSH'ing in and running tail -f but from your browser. Requires SSH relay.

6

Remote Controls

Buttons to restart OpenClaw, kill a runaway task, pause all crons, trigger a specific workflow. The "intervene" panel. Requires SSH relay.

7

Revenue & ROI

Track what OpenClaw has earned or produced: deals closed, tasks completed with business value, revenue attributed to automated workflows. Cost vs. value.
