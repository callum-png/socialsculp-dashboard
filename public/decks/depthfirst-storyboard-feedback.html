DepthFirst Launch Video

7 scenes · Design stage (pre-animation) · March 6, 2026

Reference Philosophy (Slash)

Abstract concept (not UI-based) → abstract, branded visual. Concrete feature (lives in the product) → one-to-one UI representation. Avoid repeating the same screen or action — new stimulus = more engaging. When in doubt: can we show the actual thing? If yes, show it. If no, go abstract.

Overall the script is strong — clear problem, product, proof, CTA. The main opportunity is tightening the abstract vs. concrete split per scene so we don't over-rely on one visual language. Scene 3 (login bug) and Scene 5 (AI writes fix) are concrete UI moments — they should feel one-to-one. Scenes 1, 2, 4, 6 are abstract — the halftone/logo treatment works, but we need variety so it doesn't feel like the same frame seven times. Also: sound-off test — key claims (10x faster, 30 seconds, ServiceNow/Lovable/Supabase, comment "depthfirst") should be readable with mute on.
